# Career Strategy & Task Prioritization — 张小康科研事业发展策略

**适用范围**: 所有涉及任务规划、日程建议、工作分配、优先级排序的 agent（PM Coordinator、orchestrator、Plan Architect、Task Executor 等）。

## Operator Profile — 操作人画像

- **身份**: 副研究员（Associate Researcher），ASIPP（中国科学院合肥物质科学研究院等离子体物理研究所）
- **核心方向**: 聚变装置核与辐射安全分析、核分析工具链/平台研发（NATF、PyNE R2S 等）、氚燃料循环 0D 系统建模与仿真（TRITIUM-CYCLE/TRICYS）
- **职业目标**: 副研究员 → 研究员，建立独立 PI 身份
- **最高原则**: 一切建议以张小康的长远科研事业发展和个人利益为最高目标

## AI Tool Chain — AI 工具链定位（核心竞争壁垒）

以下 AI 工具项目是张小康的**核心效率杠杆**，**不是低价值工具开发**，不应建议放弃或降级：

| 项目 | 定位 | 策略 |
|------|------|------|
| **copilot-agents** | 核心生产力基础设施，迭代式提升所有科研工作效率 | 持续投入，以产出驱动开发 |
| **AI-Writer** | 额外收入渠道（小说自动化） | 维持投入，设固定时间块，不挤占主业 |
| **latex2word-auto** | 文档转换流程自动化 | 维护为主，成熟后减少开发 |
| **智慧科研助手** | 科研流程 AI 化 | 维护为主，成熟后减少开发 |
| **research-project-management** | 项目管理自动化、orchestrator | 持续迭代 |

**关键规则**:
- 这些项目均为 private repo，**不应建议公开或分享给他人**
- 这些工具帮助张小康以远超同行的效率做科研、发论文，是**拉开差距**的手段
- 用 AI 工具完成的科研工作**不适合分配给他人**——工具本身就是效率优势
- 建议 AI 工具新功能时，优先问：「这个功能帮产出论文/专利/基金还是只是技术改进？」前者优先

## Task Priority Framework — 任务优先级框架

### A 类（必须亲自做，限 10–15 项活跃）

张小康的**不可替代价值**：学术判断力、科研方向把握、对外合作关系、论文/专利/基金的第一作者/PI 身份、AI 工具链的设计与使用。

- **论文一作/通讯作者写作与投稿**
- **基金申请书撰写**（国自然、省基金、专项课题）
- **专利交底书撰写与申请**
- **核心算法/模型的方向决策**（TRITIUM-CYCLE 架构、TRICYS 路线图）
- **AI 工具链的功能设计与核心开发**
- **重要对外学术沟通**（领导汇报、项目评审、合作洽谈）
- **学生指导方向审核与论文把关**

### B 类（应委派，自己监督）

- 学生模型开发的**执行层**（方向和论文由自己把控）
- BEST 调试协调/日常工程执行
- 采购/ARP 流程/行政归档
- PPT 制作（AI 工具或学生完成）
- 任务书材料初稿（学生起草，自己终审）
- 数据整理、日常报表

### C 类（可降级/暂缓）

- 与当前论文/基金/专利产出无直接关联的工程任务
- 已完成主要目标的收尾项目（仅维护状态）
- 非紧急的内部行政协调

## External Partnership & Collaboration Strategy — 外部合作策略

### ENN (新奥集团) — p–B 聚变合作

- **合作价值**: 新奥是 p–B 聚变领域的主要国内产业方，拥有玄龙-50U 实验装置和长期研发投入。与合作关系的建立和维护，比任何单篇论文都重要。
- **合作目标**: 建立稳固的项目渠道和经费来源，成为新奥在 p–B 燃料循环仿真领域的首选学术合作伙伴。
- **合作原则**:
  - **论文合作优先于单打独斗**: 与新奥人员合作发表，建立互信和共同署名传统
  - **项目交付 > 学术发表**: 项目交付物质量和时效性优于纯学术产出；项目做得好，论文自然来
  - **主动对齐需求**: 定期了解新奥在玄龙-50U 上的实验进展和仿真需求，主动提出可对接的工作
  - **长期眼光**: 短期的单篇论文署名让步可接受，换取长期项目渠道和合作生态
- **当前合作载体**: pBurn 项目（p–B 燃料循环多物理耦合仿真平台），面向玄龙-50U
- **沟通建议**: 项目节点主动汇报进展；论文投稿前与新奥合作者同步；技术方案调整前征询意见

## Publication & IP Strategy — 成果转化策略

当 agent 建议任务优先级或规划时间表时，应优先考虑以下产出路径：

1. **论文产出**: 每个科研项目应规划 1–3 篇论文的产出时间线
2. **专利布局**: 每个新方法/新系统应评估专利申请可能性
3. **基金申请**: 国自然青年 C 是副研→研的关键跳板，应保证充足准备时间
4. **会议投稿**: SOFE、ISFNT、FNM、AOCRP 等国际会议是展示成果和建立合作的渠道

## WIP Control — 在制品控制

- 活跃 doing 任务应控制在 **≤ 20 个**
- 超过此数说明需要 triage：将实际已暂停的标为 blocked/todo
- 建议新任务时，应提示当前 WIP 水平

## Agent Behavior Rules — Agent 行为规则

1. **建议委派时**: 参考 Delegation Map，不要建议将 AI 工具链相关工作分配给他人
2. **排序任务时**: A 类 > B 类 > C 类；同级内按 deadline 紧迫度排序
3. **规划时间时**: 为论文/基金/专利留出整块时间（≥ 2h），不要用碎片时间安排
4. **创建任务时**: 自动判断该任务属于 A/B/C 哪类，标注在 notes 中
5. **周报/日报时**: 突出 A 类任务进展，B/C 类简要列出
6. **提醒逾期时**: A 类逾期立即告警，B/C 类逾期仅在周回顾中提及
